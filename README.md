# Pesquisa de Satisfação - TudoWeb

Atividade prática de Lógica de Programação - Empresa de Marketing TudoWeb.

## 📋 Objetivo
Desenvolver um programa em Python que utilize estrutura de repetição para coletar a opinião de 50 clientes sobre o atendimento.

Opções de opinião:
- 1: EXCELENTE
- 2: BOM
- 3: RUIM

## ⚙️ Tecnologias
- Python 3.x
- Estrutura de repetição `for`
- Estrutura de decisão `if/elif/else`

## 💻 Código
O código principal está no arquivo `pesquisa.py`

O programa solicita:
1. Nome do entrevistado
2. Idade
3. Opinião (1, 2 ou 3)

Ao final exibe:
- a) Quantidade de respostas EXCELENTE
- b) Quantidade de respostas RUIM

## ▶️ Como executar
```bash
python pesquisa.py
